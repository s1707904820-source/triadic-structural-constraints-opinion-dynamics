# Data provenance

No simulations were rerun while assembling this archive. The files in this directory were copied from the formal outputs used for the revision. The original machine-specific directory hierarchy is not required for reuse; the result-to-file map below identifies every preserved output within this archive.

- Update-fraction sensitivity: `exp8_mu_sweep.json` and `exp8_mu_sweep.meta.json`.

- Holme--Kim connectivity sensitivity: `exp8_m_robustness.json` and `exp8_m_robustness.meta.json`.
- Initial-opinion-distribution sensitivity: `exp8_init_distribution.json` and `exp8_init_distribution.meta.json`.
- Terminal six-endpoint AUC contrasts: `tableS1_terminal_auc_contrasts.csv`.
- Global and segmented trajectory contrasts: `tableS2_trajectory_global_contrasts.csv` and `tableS3_trajectory_segments.csv`.
